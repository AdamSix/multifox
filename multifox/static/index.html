multifox

Run many isolated Firefox browsers side by side — each with its own fingerprint and exit IP. Stop wipes everything.

Proxy settings

Each identity routes all its traffic through its own SOCKS5 proxy, so every identity gets a different exit IP. When you press Start, a GeoIP lookup is sent through each proxy so the identity's timezone, locale and geolocation match its exit IP — the proxies must be up at that moment.

Format: one host:port per line, in identity order (id1, id2, …). Lines starting with # are comments. DIRECT means no proxy for that identity (your real IP). Two identities sharing an exit IP are linked, so every line should be a different egress — e.g. SSH tunnels: ssh -N -D 127.0.0.1:1081 user@vps1, then list 127.0.0.1:1081 here.
